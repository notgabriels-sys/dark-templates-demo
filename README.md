# Dark Templates — live demos

Live previews of the dark HTML template packs: business documents, slide decks and app screens.

**Demo site:** https://notgabriels-sys.github.io/dark-templates-demo/

A subset of each pack is published here so you can judge the real output before buying.
Plain HTML and CSS — no framework, no build step, no dependencies.

- **Business documents** — invoice and EU reverse-charge invoice (2 of 9)
- **Slides** — investor pitch deck (1 of 3)
- **App screens** — dashboard and sign in (2 of 6)
- **Docs site** — home, quickstart, API reference, changelog with working search (4 of 9)
